# نصب ربات فروش FARSTAR

**دریافت لایسنس رایگان یک‌ماهه فقط در [@FARSTAR_VPN_BOT](https://t.me/FARSTAR_VPN_BOT)**

در انتهای منوی ربات، «ربات خودت را بساز · لایسنس رایگان» را بزن. کلید شخصی و دستور نصب نمایش داده می‌شود. هر حساب یک لایسنس آزمایشی می‌گیرد؛ اعتبار ۳۰ روز از اولین فعال‌سازی شروع می‌شود. ادمین اصلی نصب باید همان حساب دریافت‌کننده لایسنس باشد. تمدید و انتقال با مدیر FARSTAR است.

## دستور نصب

سرور Debian 12 یا Ubuntu 24.04، Python 3.11+، curl، دسترسی root و اتصال به GitHub، مرجع لایسنس و Telegram لازم است:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/farstar-team/FARSTAR-ROBOT/main/install.sh)
```

نصاب به ترتیب لایسنس، توکن BotFather، آیدی ادمین، نام فروشگاه، کارت و نام حساب، پشتیبانی و تنظیم مینی‌اپ را می‌پرسد. اطلاعات محرمانه در خط فرمان یا مخزن ثبت نمی‌شود. پورت مستقل باید آزاد باشد؛ اگر مسیر نصب قبلی پیدا شود نصاب متوقف می‌شود و داده قبلی را بازنویسی نمی‌کند. بسته از commit مشخص GitHub دریافت و SHA-256 آن با مرجع تطبیق داده می‌شود.

نصاب فقط بسته‌های لازم برای Python را نصب می‌کند؛ سیستم‌عامل، پنل ثنایی، Xray، اینباندها، پورت‌های موجود و فایروال را تغییر نمی‌دهد. اطلاعات ورود ثنایی داخل نصب پرسیده نمی‌شود؛ آن را بعداً در مدیریت خود ربات اضافه کن. برای نصب تازه هیچ پلن پولی یا تستی خودکار فعال نمی‌شود.

در صورت خطای نصب، تنظیمات پنل قبلی دست‌نخورده می‌ماند. برای حفظ داده، مسیر نیمه‌تمام به صورت خودکار حذف/بازنویسی نمی‌شود. اگر سرویس ساخته شده است، `systemctl status farstar-robot.service` و راهنمای پشتیبانی را بررسی کن؛ از پاک کردن دیتابیس یا فایل کلید خودداری کن.

## راه‌اندازی فروشگاه

۱. به ربات خودت `/start` و `/admin` بفرست.

۲. «سرورها ← افزودن پنل ثنایی» یا مینی‌اپ/داشبورد «سرورها» را باز کن. آدرس کامل پنل همراه مسیر اختصاصی، توکن API با scope admin، آدرس پایه Subscription، یک اینباند پایه و ظرفیت را وارد کن. اتصال را بررسی کن.

۳. همه اینباندهای فعال به صورت پیش‌فرض انتخاب می‌شوند. پروتکل‌ها: VLESS، VMess، Trojan، Shadowsocks، Hysteria و TUIC، در صورت وجود و پشتیبانی در پنل خودت. فیلتر خالی یعنی همه؛ شناسه نود `0` یعنی محلی، شناسه‌های دیگر مطابق `nodeId` اینباندهای ثنایی هستند. «نود» در این نسخه نود مدیریت‌شده توسط ثنایی است؛ سرور مستقل را به عنوان یک پنل جدا اضافه کن. فقط اینباندهای موجود خوانده و مشتری فروشگاه به آن‌ها متصل می‌شود؛ اینباند یا ترنسپورت جدید ساخته نمی‌شود.

۴. پلن‌های حجم/مدت/قیمت خودت و شماره کارت را ثبت کن. از «نام، متن و لوگو» هویت فروشگاهت را تغییر بده. متن‌ها ساده‌اند و HTML یا کد اجرا نمی‌شود. فقط یک لوگوی بهینه در دیتابیس نگهداری می‌شود. تغییر نام نمایشی پروفایل تلگرام از داخل مدیریت قابل اعمال است؛ تغییر @username با BotFather انجام می‌شود.

۵. یک خرید و رسید واقعی کم‌مبلغ را با اکانت خودت بررسی کن. تأیید فیش باید مستقیماً اشتراک، لینک و QR را تحویل بدهد. رسیدها روی دیسک به عنوان عکس انبار نمی‌شوند.

## مینی‌اپ و HTTPS

ربات تلگرام بدون دامنه هم کار می‌کند. مینی‌اپ مدیر و کاربر به دامنه و گواهی معتبر خودت نیاز دارند. نصاب می‌تواند از گواهی و کلید موجود آن دامنه با `LoadCredential` در systemd استفاده کند و روی یک پورت آزاد مستقل مثل `18443` HTTPS بدهد؛ کلید اصلی گواهی جابه‌جا یا بازنویسی نمی‌شود. دامنه باید به همین سرور اشاره کند و گواهی با آن تطابق داشته باشد. پس از تمدید گواهی، فقط سرویس ربات را restart کن.

اگر از reverse proxy موجود خودت استفاده می‌کنی، ربات را روی loopback نگه دار و مسیرهای `/app`، `/admin-app`، `/mini-api/*`، `/api/*`، `/brand/logo` و `/static/*` را به پورت مستقل ربات بفرست. نمونه در `docs/Caddy-miniapp.example` است. پراکسی پنل فعلی را بدون بررسی تغییر نده.

در `/etc/farstar-robot/bot.env` آدرس‌ها را تنظیم کن:

```dotenv
PUBLIC_URL=https://shop.example.com
MINI_APP_URL=https://shop.example.com/app
ADMIN_MINI_APP_URL=https://shop.example.com/admin-app
COOKIE_SECURE=true
```

سپس فقط `systemctl restart farstar-robot.service`. دامنه و Menu Button را در BotFather بررسی کن. تنظیمات HTTPS فعال سرویس را با پیکربندی پراکسی هماهنگ نگه دار.

## رفتار لایسنس و اطلاعات ارسالی

لایسنس رسمی با امضای Ed25519 و اتصال به شناسه ربات، شناسه نصب و اثر انگشت سرور بررسی می‌شود. هر ۶ ساعت بررسی دوره‌ای انجام می‌شود؛ در قطعی مرجع، آخرین مجوز امضاشده حداکثر تا ۷۲ ساعت و هرگز بیشتر از تاریخ انقضای لایسنس معتبر است. فروش جدید در نبود مجوز معتبر متوقف می‌شود؛ سرویس‌های VPN موجود، تحویل سفارش پرداخت‌شده، پشتیبانی و بکاپ باقی می‌مانند. غیرفعال‌سازی از راه دور در بررسی بعدی اعمال می‌شود، نه بلافاصله در یک نصب آفلاین.

در فعال‌سازی، کلید لایسنس، شناسه ادمین، شناسه نصب، هش شناسه ماشین و توکن ربات برای تأیید `getMe` روی HTTPS به مرجع FARSTAR ارسال می‌شوند. توکن در مرجع ذخیره نمی‌شود. پس از آن فقط اعتبارنامه مخصوص نصب، شناسه نصب، هش شناسه ماشین و شناسه ربات برای heartbeat ارسال می‌شود؛ اطلاعات پنل، کارت، مشتری و فروش ارسال نمی‌شود.

مرجع صدور و کلید خصوصی داخل نسخه عمومی نیست. نصب مشتریان دکمه صدور یا پنل مدیریت لایسنس دیگران ندارد. کد عمومی قابل مطالعه و تغییر است؛ این طرح کنترل نصب رسمی است و تضمین ضدکپی برای کد اجراشونده با دسترسی root نیست. نسخه‌های قدیمی دانلودشده قابل پس‌گرفتن نیستند.

## نگهداری

```sh
systemctl status farstar-robot.service
journalctl -u farstar-robot.service -n 50 --no-pager
```

پیکربندی: `/etc/farstar-robot/bot.env`؛ داده: `/var/lib/farstar-robot`؛ برنامه: `/opt/farstar-robot/current`. فایل env و دیتابیس را خصوصی پشتیبان بگیر. `SECRET_KEY`، شناسه و توکن نصب را حفظ کن. این فرمان نصاب، نصب تازه است؛ برای به‌روزرسانی همان نصب دوباره اجرا نکن. راهنمای استقرار نسخه‌ای و برگشت امن در `SAFE_DEPLOYMENT.md` است. برای جابه‌جایی سرور یا تمدید به [@FARSTAR_VPN_BOT](https://t.me/FARSTAR_VPN_BOT) مراجعه کن.
